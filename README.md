# Campus Nest: прототип с бесплатным AI на GitHub Pages

Схема работы:

```
GitHub Pages (index.html)  →  Cloudflare Worker (worker.js)  →  Workers AI (модель GLM-4.7-Flash)
```

- Бесплатно: на тарифе Workers Free даётся 10 000 «нейронов» в день. Одна подсказка в прототипе тратит примерно 10–20 нейронов, то есть хватает на сотни запросов в день.
- Банковская карта и API-ключ не нужны. Модель подключается к Worker напрямую через привязку (binding).
- Если дневной лимит закончится, новые запросы просто перестанут проходить до 00:00 UTC. Деньги на бесплатном тарифе списать невозможно, а прототип при этом сам переключится на запасную логику.

## 1. Создать Worker (10 минут)

1. Зарегистрируйтесь на <https://dash.cloudflare.com> (бесплатно).
2. Откройте **Workers & Pages → Create → Create Worker** (шаблон Hello World). Назовите его `campus-nest-ai` и нажмите **Deploy**.
3. Нажмите **Edit code**, удалите весь код, вставьте содержимое `worker.js` и снова нажмите **Deploy**.
4. Подключите модель: **Settings → Bindings → Add → Workers AI**. В поле **Variable name** напишите `AI` (большими буквами), затем **Save / Deploy**.
5. Скопируйте адрес Worker. Он выглядит так: `https://campus-nest-ai.<ваш-ник>.workers.dev`.
6. Проверьте адрес в браузере. Должна открыться строка «Campus Nest AI proxy is running».

## 2. Подключить сайт

В файле `index.html` найдите строку:

```html
<meta name="cn-ai-endpoint" content="">
```

Вставьте в неё адрес вашего Worker:

```html
<meta name="cn-ai-endpoint" content="https://campus-nest-ai.<ваш-ник>.workers.dev">
```

## 3. Выложить на GitHub Pages

1. Создайте публичный репозиторий, например `campus-nest`.
2. Загрузите в него `index.html`: **Add file → Upload files → Commit**.
3. Откройте **Settings → Pages**, выберите **Source: Deploy from a branch**, затем **Branch: main** и папку **/ (root)** и нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-ник>.github.io/campus-nest/`.

## 4. Защитить лимит (рекомендуется)

Чтобы чужие сайты не тратили ваш лимит, откройте в Cloudflare **Worker → Settings → Variables and Secrets → Add** и задайте:

- Name: `ALLOWED_ORIGIN`
- Value: `https://<ваш-ник>.github.io` (без слеша в конце и без названия репозитория)

Кроме того, Worker сам принимает только четыре задачи прототипа, поэтому использовать его как обычный чат-бот не получится.

## 5. Как проверить, что AI работает

Откройте вкладку **Roommates**. В блоке «Why this score» должна появиться метка **Live · Cloudflare AI**. Если вместо неё видна метка **Offline rules**, проверьте:

- адрес в `<meta>` (без лишних пробелов, начинается с `https://`);
- что привязка Workers AI называется именно `AI`;
- что `ALLOWED_ORIGIN` совпадает с адресом сайта.

Подробная ошибка видна в консоли браузера (F12 → Console) и в логах Worker (**Worker → Logs**).

## Где AI в прототипе

| Экран | Что делает модель |
|---|---|
| S1.2 Roommates | Объясняет процент совместимости с учётом того, что важно именно вам |
| S1.3 Matches | Находит главный бытовой конфликт с каждым мэтчем |
| S3.2 Group Profile | Называет главный риск группы и предлагает правило для квартиры |
| M1.2 Chat | Предлагает вопросы для начала разговора на общем языке; видит только профили, переписку не видит |

Сам процент совместимости считает формула: так он быстрый и одинаковый при каждом открытии, а модель его объясняет.

## Сменить модель

В начале `worker.js` есть строка `const MODEL = ...`. Туда можно подставить любую модель для генерации текста из каталога Workers AI, например DeepSeek: `@cf/deepseek-ai/deepseek-r1-distill-qwen-32b`. DeepSeek думает дольше и тратит заметно больше бесплатного лимита.
